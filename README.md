# stafera-site

Static site (plain HTML/CSS/JS).

## Run locally (localhost)

Option A (recommended):

- `python3 serve.py`
- Open `http://127.0.0.1:8000/`

Option B (built-in Python server):

- `python3 -m http.server 8000`
- Open `http://127.0.0.1:8000/`

## Accessibility / JAWS quick checks

- Keyboard: `Tab` through the top navigation, open/close the menu with the “Menu” button, and use `Esc` to close.
- Screen reader: headings should be a clean outline (single main `h1` per page) and screenshots have meaningful `alt` text.
